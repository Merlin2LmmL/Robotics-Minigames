View

World keeps the map still. Robot keeps the robot still and rotates the map.

Map

Switching puts the robot back at the start.

Editor

Color and Pushable change the selected shape, or the next one drawn when nothing is selected. Only rectangles and circles can be pushed. Delete removes the selection, Ctrl+Z undoes, the mouse wheel zooms and right-drag pans.

Turn the editor off to drive the sandbox map. Maps are saved in this browser and can be exported as .json files; importing one loads it into the sandbox.

Zoom

Environment

On draws the walls and obstacles. Off hides them, leaving only the lidar beams and their hit points.

Drive

Hold a button to drive. Keyboard WASD and arrow keys work too.

The IMU measures acceleration (right is positive sideways) and turn rate, both with noise and a small constant bias; the wheels report forward speed with noise and a small wheel size error. The purple outline is where the robot would think it is using only the gyro and the wheels, and it drifts further from the truth the longer you drive.
